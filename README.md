# Professional Brand — Riccardo Cremaschi

Portfolio professionale statico, realizzato con HTML, CSS e JavaScript senza framework o dipendenze di build.

## Struttura
- `index.html` — homepage, sezioni e pannelli di approfondimento
- `styles.css` — stile responsive
- `script.js` — contenuti delle schede e navigazione

## Pubblicazione
Il sito è predisposto per GitHub Pages e si apre da `index.html`. Impostare **Settings → Pages → Deploy from a branch → main / (root)** se non è già attivo.

## Contenuti
Le informazioni professionali derivano dal CV pubblico nel repository `riccardocremaschi/cv`. I recapiti personali (email e telefono) sono deliberatamente esclusi. La foto è caricata dal repository CV esistente.
